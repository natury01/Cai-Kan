## หลังบ้าน

**Supabase** (โปรเจกต์ `janoonnhzpwjnxqjvswt`) เป็นที่เก็บข้อมูลทั้งหมด — ห้องเรียน รายชื่อนักเรียน
คะแนนรายข้อ เซฟเกม สื่อห้องเรียนรู้ ตัวชี้วัด และสิทธิ์ผู้ดูแล

Google Apps Script / Google Sheets **ถูกตัดออกจากตัวเกมแล้ว 100%** ตั้งแต่เฟส 3e
(ไฟล์ `Code.gs` เก็บไว้เพื่อย้ายข้อมูลเก่าเท่านั้น ไม่มีการเรียกใช้ระหว่างเล่น)

คีย์ที่ฝังใน `index.html` เป็น **anon key** ซึ่งปลอดภัยตามการออกแบบของ Supabase (ถูกจำกัดสิทธิ์ด้วย RLS)
— service_role key ห้ามอยู่ในไฟล์นี้เด็ดขาด

## การนำขึ้นใช้งาน

1. เปิด Supabase → SQL Editor → วางไฟล์ `supabase_patch_all_v7994.sql` ทั้งไฟล์ → Run (รันซ้ำได้ ไม่เสียข้อมูล)
2. อัปโหลด `index.html` และ `dashboard.html` ขึ้น Cloudflare Pages (deploy อัตโนมัติเมื่อไฟล์เปลี่ยน)
3. เข้าหน้าครู → เข้าสู่ระบบด้วย Google → สร้างห้องเรียน → แจกโค้ดหรือลิงก์ `?join=CODE` ให้นักเรียน

## ลิงก์พิเศษ (สำหรับครู)

| ลิงก์ | ใช้ทำอะไร |
|---|---|
| `?join=CODE` | เปิดเกมพร้อมกรอกโค้ดห้องให้อัตโนมัติ — ส่งลิงก์นี้ให้นักเรียนได้เลย |
| `?demo=1` | โหมดสาธิต: เล่นได้ทุกอย่าง เหรียญเต็ม ปลดล็อกครบ แต่**ไม่บันทึกคะแนน ไม่ขึ้นกระดานอันดับ** |
| `?admin=1` | เปิดเมนูเข้าสู่ระบบสำหรับครู (หรือแตะป้ายเวอร์ชันมุมซ้ายล่างหน้าแรก 5 ครั้ง) |
| `?dev=1` | เมนูข้ามด่าน + มาตรวัด FPS สำหรับตรวจงานระหว่างพัฒนา |

## หมายเหตุสำหรับผู้ดูแลโค้ด

- ไฟล์ชุดนี้ **สร้างด้วย `python3 build_repo.py`** อย่าแก้ `repo/index.html` หรือ `repo/dashboard.html` โดยตรง
  — แก้ที่ `game.html` แล้วสั่ง build ใหม่ (เลขเวอร์ชันใน README นี้ดึงจาก `GAME_VERSION` อัตโนมัติ)
- ข้อความข้อสอบเป็นเครื่องมือวิจัย **ห้ามแก้โดยไม่ได้รับคำสั่ง**
- ข้อมูลที่บันทึกใช้ `logId` เดิมเสมอแม้เปลี่ยนรูป/ไอคอน เพื่อให้ข้อมูลวิจัยต่อเนื่อง
